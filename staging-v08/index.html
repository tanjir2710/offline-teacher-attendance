Persistent storage reduces the chance that the browser automatically removes local attendance data. It cannot protect against deleting app/site data or losing the device.

Install / Run Correctly

  1. First visit requires internet. Open the GitHub Pages link once so the app files can be cached.
  2. Install while online. Tap Install app when available. On iPhone/iPad: Safari → Share → Add to Home Screen.
  3. After installation: open the app and take attendance with no internet.
  4. When internet returns: online features work again; cloud backup/sync can then run.

The installed app keeps attendance on the device. Clearing browser/app data removes that local copy, which is why cloud backup is the next safety layer.
